# 报关单 PDF 解析（第一批：干净数据）

## 目标

把 `data/raw/customs_declaration/` 下的报关单原件解析成**结构固定、可直接比对**的
Excel，字段口径对齐飞书多维表「2026年报关记录 AI」，为后续成本匹配提供干净输入。

输出按单据类型分成两份（`outputs/customs_parse/`）：

| 文件 | 内容 | 用途 |
| --- | --- | --- |
| `报关单解析结果_出口退税联.xlsx` | 正式报关单（JG09 出口退税联） | 进入成本匹配 |
| `报关单解析结果_预录单.xlsx` | 「仅供核对用」版式，对应飞书预录单 | 单独留档，不参与成本匹配 |

## 用法

```powershell
& '.\.venv\Scripts\python.exe' scripts\parse_customs.py          # 批量解析并写 Excel
& '.\.venv\Scripts\python.exe' scripts\verify_parse_vs_feishu.py  # 与飞书逐份比对
& '.\.venv\Scripts\python.exe' scripts\probe_pdf_layout.py        # 导出 PDF 文本（调试用）
```

代码位置：`app/services/parser/`

| 文件 | 职责 |
| --- | --- |
| `pdf_text.py` | 从 PDF 抽文本（默认模式优先，layout 兜底） |
| `declaration_parser.py` | 版式识别 + 表头/商品明细解析 |
| `models.py` | `DeclarationHeader` / `DeclarationItem` / `ParsedDeclaration` |
| `output_columns.py` | 输出列定义、`合同号（应收表格）→合同号` 公式 |
| `excel_writer.py` | 写出固定列顺序的 xlsx |

## 版式识别

抽查 416 份 PDF 后发现两种版式，解析器自动分流：

| 版式 | 特征 | 取向方式 |
| --- | --- | --- |
| 1（JG09 出口退税联，383 份） | 有 `海关编号：`、`境内收发货人(` | 标签行在值上方 |
| 2（仅供核对版式，33 份） | 首行 `*海关编号*`、`仅供核对用`、`监管方式` | 值在标签上方，商品区带 `项号` |

## 字段映射（按你的说明）

| 报关单 | 输出列 | 说明 |
| --- | --- | --- |
| 合同协议号 | `合同号_1` | 报关单上的合同号（通常即出运单号） |
| 海关编号 | `报关单号` | 18 位海关编号 |
| 合同协议号 | `合同号（应收表格）` | 出运单号原文 |
| 合同号（公式） | `合同号` | 按下面公式在 Python 中复算 |
| 运费 / 保费 / 杂费 | 不输出 | 按要求不解析 |

合同号推导（`output_columns.derive_contract`，与飞书公式一致）：

```
长度 ≤ 11                -> 原样
第 12 位 = Y             -> 取前 12 位
第 12 位起 = ADD/ ADD/-ADD -> 原样
其它                     -> 取前 11 位
```

飞书上由**查找/公式**得到的字段（产品类型、退税率、供应商、报关金额、汇率、出运日期、
客户代码、国家、业务员、部门、采购金额等）照常保留成列，PDF 无法解析到的留空。

## 合同号的两种异常形态（已兼容）

少数报关单的合同号过长被系统截断，剩余部分落到「标记唛码及备注」：

| 文件 | 表头 `合同协议号` | 备注 | 处理 |
| --- | --- | --- | --- |
| `SMPdbRklEoyWGwxtzcacz6m9nUb.pdf` | `26MT-03P200Y-A&229Y-A&245Y-A&` | `合同协议号: 262Y-A` | 拼接续写，补回前缀 |
| `NOatb3G8koBTuNx8nRvco3Pcnug.pdf` | `26MT-03P200Y-A&229Y-A&245Y-` | `合同协议号: 26MT-03P200Y-A&229Y-A&245Y-A&262Y-A`（完整重写） | 取备注的完整值 |

两者最终都还原为 `26MT-03P200Y-A&229Y-A&245Y-A&262Y-A`；同时兼容最小重复写法
（`26MT-06N100&110&140`、`26MT-06M052&087A`、`26MT-10E185A&228ADD`）。
飞书这两条目前仍是截断值，属**解析增强**而非差异。

## 与飞书差异的说明（非解析缺陷）

1. **重复 PDF**：29 组报关单在 `data/raw/customs_declaration/` 下存在多份同内容文件
   （如 `310120260516673776` 有 4 份），结果中用 `重复来源文件` 列标注。
2. **重量差异 5 份**：飞书端在 PDF 解析结果之上又做过**人工拆单/改动**，
   因此与报关单原始净重不一致（例如 `223320260001346587` 的 26kg 被改成 1076）。
   本条以**报关单原件**为准，飞书是随后被人工加工过的结果。
3. **飞书拆分**：同一报关单在飞书会按「产品类型/供应商」拆成多行，逐行重量本就
   与报关单合计不等，需按报关单号汇总后再比对（本报告已按此口径）。

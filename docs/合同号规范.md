1. 合同号本体：26MT-0KXXXX,两位年份，MT标识公司主体，0K标识部分，1位标识员工在部门内代号，三位表示此员工本年度接单数。
2. 外销单，外销单必须在开头加PI-,,Y表示本单有佣金，且有Y的外销订单在出运单、采购单中也必须有Y，ADD或-ADD标识本单是附加订单可以添加在订单最后，多个附件单则按照序号顺延，如ADD1,ADD2,ADD3,ADD4,其中ADD1有时会被允许写成ADD(不带1），我们勉强不算错。
3. 采购单，前缀（包括Y、ADD)需要与对应的外销单一致，其后可以有对应的工厂简称首字母缩写，比如-YH,-HD,也可以是中文名：-永恒、-鸿迪。缺少-一律不算错。采购单的采购批次规范分新旧两版，旧版是-A,-B或A,B代表采购批次，如果采购都来自同一家工厂，可以直接写-A,-B,不写工厂简称缩写，如果订单来自同一家公司且只有一批，可以什么都不写。新规范要求，无论是否来自同一家公司，都需要有工厂简称（注意不是缩写），批次则必须要用-1-2标注，最终应该写成-1-鸿迪，-2-鸿迪。新版具体规则可以见[采购合同命名规则_新版](采购合同命名规则_新版.csv)
4. 出运单，出运单总体由采购单决定，如果一次出运只涉及一个采购单，则出运单号就是采购单号，如果一次出运包含多个订单内容，则包含多个采购单，用&连起来，且基本符合最小重复原则，如26MT-01S180&190&241标识26MT-01S18、266MT-01S190、26MT-01S241三个，其中相同部分被重复，再比如26MT-06H251&ADD1表示26MT-06H251和26MT-06H251-ADD1,ADD在哪，就表示它是前一个订单的附加订单。

# 报关任务代理接口

## 链路

1. 飞书按钮请求服务器创建任务。
2. 任务写入服务器本地持久队列。
3. 财务内网电脑轮询并领取任务。
4. 财务电脑抓取 PDF 后上传到服务器。
5. 服务器自动解析 PDF、拆单、执行成本匹配、写入飞书副本表。
6. 任务进入 `completed` 或 `failed` 后，服务器删除本任务的 PDF 和中间文件，只保留 `task.json`、`result.json`。

服务器不再负责登录海关网站或下载 PDF。

## 配置

在服务器 `.env` 中配置：

```dotenv
CUSTOMS_TASK_CREATE_TOKEN=请替换为飞书建任务专用随机长令牌
CUSTOMS_AGENT_TOKEN=请替换为财务电脑代理专用随机长令牌
CUSTOMS_FEISHU_VERIFICATION_TOKEN=请替换为飞书回调验证令牌
CUSTOMS_AGENT_LEASE_SECONDS=900
CUSTOMS_MAX_PDF_FILES=500
CUSTOMS_MAX_PDF_MB=20
CUSTOMS_MAX_TOTAL_MB=500
```

飞书写回仍使用现有的副本表配置：

```dotenv
MT_FINANCE_AI_COPY_APP_TOKEN=...
MT_FINANCE_AI_COPY_TABLE_ID=...
```

副本表会自动补齐以下字段：

- `报关单号`
- `pdf原件`
- `合同号AI`
- `报关金额AI`
- `报关重量AI`
- `采购金额AI`
- `采购金额分摊依据AI`
- `拆单状态`
- `成本匹配状态`

部署时建议只启动一个 Uvicorn worker，当前队列和后台处理线程按单进程服务器设计。

## 本机最快实测

先启动服务：

```powershell
cd "E:\财务\cost matching\cost_matching_ultra"
.\.venv\Scripts\python.exe -m uvicorn app.main:app --host 127.0.0.1 --port 8765
```

仓库中的 `scripts/customs_agent_api_smoke.ps1` 会自动从 `.env` 读取令牌，
可以直接在 Windows PowerShell 5.1 中运行，不需要手工替换令牌：

```powershell
# 1. 创建任务
powershell.exe -NoProfile -ExecutionPolicy Bypass `
  -File .\scripts\customs_agent_api_smoke.ps1 `
  -Action create -StartDate 2026-10-01 -EndDate 2026-10-27

# 2. 模拟财务电脑领取；把上一步返回的 taskId 填到 -TaskId
powershell.exe -NoProfile -ExecutionPolicy Bypass `
  -File .\scripts\customs_agent_api_smoke.ps1 `
  -Action claim -AgentName finance-pc-01

# 3. 上传文件；一次可传多个 -Pdf
powershell.exe -NoProfile -ExecutionPolicy Bypass `
  -File .\scripts\customs_agent_api_smoke.ps1 `
  -Action upload -TaskId <TASK_ID> -AgentName finance-pc-01 `
  -Pdf "D:\customs\a.pdf","D:\customs\b.pdf"

# 4. 查询状态和结果
powershell.exe -NoProfile -ExecutionPolicy Bypass `
  -File .\scripts\customs_agent_api_smoke.ps1 `
  -Action status -TaskId <TASK_ID>

powershell.exe -NoProfile -ExecutionPolicy Bypass `
  -File .\scripts\customs_agent_api_smoke.ps1 `
  -Action result -TaskId <TASK_ID>
```

该脚本只是服务器接口自测客户端，不是财务电脑上的正式抓取程序。

## 飞书创建任务

接口：

```text
POST /api/customs/tasks
```

请求头：

```text
Content-Type: application/json
X-Customs-Task-Token: <CUSTOMS_TASK_CREATE_TOKEN>
Idempotency-Key: <按钮记录ID或本次任务唯一ID>
```

请求体：

```json
{
  "source": "feishu_button",
  "workflow": "customs",
  "flow": "both",
  "startDate": "2026-10-01",
  "endDate": "2026-10-27",
  "declarations": [],
  "contracts": [],
  "idempotencyKey": "记录ID-20261027"
}
```

`flow` 可选：`export`、`pre_record`、`both`。飞书任务创建令牌也可以放在请求体 `authToken` 字段中，避免飞书自动化无法设置请求头。

curl 示例：

```bash
curl -X POST "https://YOUR-SERVER/api/customs/tasks" \
  -H "Content-Type: application/json" \
  -H "X-Customs-Task-Token: <CUSTOMS_TASK_CREATE_TOKEN>" \
  -d '{
    "source": "feishu_button",
    "flow": "both",
    "startDate": "2026-10-01",
    "endDate": "2026-10-27",
    "idempotencyKey": "record-20261027-001"
  }'
```

成功响应：

```json
{
  "taskId": "ct_0123456789abcdef",
  "state": "queued",
  "duplicate": false,
  "queuePosition": 1,
  "statusUrl": "/api/customs/tasks/ct_0123456789abcdef"
}
```

飞书配置回调 URL 时，接口同时支持 `url_verification`，验证令牌使用 `CUSTOMS_FEISHU_VERIFICATION_TOKEN`。

## 财务电脑轮询领取

接口：

```text
GET /api/customs/tasks/claim
```

请求头：

```text
Authorization: Bearer <CUSTOMS_AGENT_TOKEN>
X-Agent-Name: finance-pc-01
```

curl 示例：

```bash
curl "https://YOUR-SERVER/api/customs/tasks/claim" \
  -H "Authorization: Bearer <CUSTOMS_AGENT_TOKEN>" \
  -H "X-Agent-Name: finance-pc-01"
```

有任务时响应包含：

```json
{
  "hasTask": true,
  "task": {
    "id": "ct_0123456789abcdef",
    "state": "claimed",
    "parameters": {
      "flow": "both",
      "startDate": "2026-10-01",
      "endDate": "2026-10-27"
    }
  },
  "uploadUrl": "/api/customs/tasks/ct_0123456789abcdef/upload",
  "statusUrl": "/api/customs/tasks/ct_0123456789abcdef",
  "heartbeatUrl": "/api/customs/tasks/ct_0123456789abcdef/heartbeat"
}
```

没有任务时返回：

```json
{"hasTask": false, "task": null}
```

领取任务后如果抓取 PDF 较慢，可定期调用：

```text
POST /api/customs/tasks/{taskId}/heartbeat
```

## 上传 PDF

接口：

```text
POST /api/customs/tasks/{taskId}/upload
Content-Type: multipart/form-data
```

请求头：

```text
Authorization: Bearer <CUSTOMS_AGENT_TOKEN>
X-Agent-Name: finance-pc-01
```

文件字段名固定为 `files`，同一任务可以上传多个 PDF。上传成功返回 HTTP `202`，服务器会自动启动后续解析、拆单、成本匹配和副本表写回。

Windows 可直接使用 `curl.exe`：

```bash
curl.exe -X POST "https://YOUR-SERVER/api/customs/tasks/ct_0123456789abcdef/upload" \
  -H "Authorization: Bearer <CUSTOMS_AGENT_TOKEN>" \
  -H "X-Agent-Name: finance-pc-01" \
  -F "agent_name=finance-pc-01" \
  -F "files=@D:/customs/224420260016128477.pdf;type=application/pdf" \
  -F "files=@D:/customs/231720260176553887.pdf;type=application/pdf"
```

PowerShell 7 文件上传示例（Windows PowerShell 5.1 不支持 `-Form`，请使用上面的 `curl.exe`）：

```powershell
$headers = @{
  Authorization = "Bearer <CUSTOMS_AGENT_TOKEN>"
  "X-Agent-Name" = "finance-pc-01"
}

$form = @{
  agent_name = "finance-pc-01"
  files = Get-Item -LiteralPath @(
    "D:\customs\224420260016128477.pdf",
    "D:\customs\231720260176553887.pdf"
  )
}

Invoke-RestMethod `
  -Method Post `
  -Uri "https://YOUR-SERVER/api/customs/tasks/ct_0123456789abcdef/upload" `
  -Headers $headers `
  -Form $form
```

## 查询状态与结果

查询状态：

```bash
curl "https://YOUR-SERVER/api/customs/tasks/ct_0123456789abcdef" \
  -H "Authorization: Bearer <CUSTOMS_AGENT_TOKEN>"
```

状态依次为：

```text
queued -> claimed -> uploaded -> processing -> completed
                                            \-> failed
```

查询业务结果摘要：

```bash
curl "https://YOUR-SERVER/api/customs/tasks/ct_0123456789abcdef/result" \
  -H "Authorization: Bearer <CUSTOMS_AGENT_TOKEN>"
```

任务结束后，`uploads/` 和 `work/` 会被删除；任务状态目录位于：

```text
.runtime/customs_tasks/<taskId>/
```

## 飞书按钮建议配置

- 方法：`POST`
- URL：`https://YOUR-SERVER/api/customs/tasks`
- 请求体：使用上一节的 JSON
- 鉴权：优先使用 `X-Customs-Task-Token`，不支持自定义请求头时使用请求体 `authToken`
- 幂等键：尽量使用按钮对应记录 ID，防止飞书重试产生重复任务
- 生产环境必须使用 HTTPS，不要让令牌出现在 URL 查询参数中

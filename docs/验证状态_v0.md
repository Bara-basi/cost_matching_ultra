## 验证结果

在已有 ERP 缓存的 55 个成功合同上离线比对（单元 = 合同号 + 报关单号 + 报关品名）：

| 结论 | 条数 |
| --- | --- |
| 金额一致（±0.02） | 50 |
| 金额不一致 | 42 |
| 因 ERP 未取到出运单而失败 | 573 |
| 跳过（内销/预录/异常合同号） | 133 |

联网仅取到 55/82 个合同的出运单；未取到的 27 个合同直接判失败，是当前失败量的主因。

## 待解决

1. **ERP 出运单查不到（27/82）**：多为 `ADD`/`ADD1` 后缀写法差异或该合同确无出运单；
   需用「采购单反查 → 出运单」或按外销订单号兜底。
2. **分摊比例**：当同一合同对应多张报关单时，逐行重量比例与人工结果仍有偏差；
   需要引入历史项目 `src/split_engine.py` 的金额锚定/重量唯一映射规则。
3. **供应商数值口径**：需确认 `采购金额` 取 **出运采购金额** 还是 **采购单总金额**。
4. **`&` 联合出运号**：`expand_combined` 已实现，尚未用真实样例回归。

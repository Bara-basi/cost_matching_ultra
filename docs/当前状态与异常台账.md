## 三、已定下来的口径

1. **产品类型 / 报关品名**：默认取报关品名的映射值（映射表没有记「其他」）；
   例外且仅此例外——同一`报关单号` + 同一`采购单号` + 同一`供应商`下拆出 ≥2 种实际品名时，
   以**实际品名**为准。
2. **报关金额 = 出运金额合计**（当前阶段不含客户费用分摊）；带客户费用分摊的记录
   暂不参与金额比对，单列异常。
3. **已人工核实的数据不再往后推进**：`data/reference/verified_conflicts.json` 里的报关单
   在下游全部整张排除（本批 16 张 / 25 条记录）。
4. 飞书有、我方没有的报关单：直接无视，不报异常、不统计。
5. **采购单号**：飞书对应列是 `合同号（应收表格）`。两侧尾缀写法不同（本地带工厂后缀
   `25MT-01P611-GYL`，飞书带批次 `26MT-01P242Y-A`），所以按 **订单核心**
   （年份+MT+部门+业务员+流水[Y][-ADDn]）比集合，不逐字符比。318/329 张一致，
   其余 9 张见「匹配结果_异常.xlsx」。
